# SRT 时间轴配音（测试功能）

此功能是 Fork 中的试验性扩展，**不是生成字幕**，而是把带时间戳的 SRT 文件配成一条对齐时间轴的 MP3。

## 使用方法

1. 启动 app.py，在右侧操作区选择 **从 SRT 按时间轴配音**（英文界面为 **Dub from SRT timestamps**）。
2. 选择现有的 SRT 文件，然后指定 MP3 保存位置。
3. 软件会使用当前主界面的**音色、语速、音量、音调**进行逐条合成；自动处理需要的静音段。若时长不够，最多尝试提高到 +100% 的语速；仍然不够就停止并报告对应字幕编号。软件**不会剪掉语音尾部**。
4. 成品只有一条 MP3，时间从原 SRT 的 00:00:00 开始。原 SRT 不变，可在剪映等工具中继续使用。

支持标准 SRT、UTF-8（含 BOM）、UTF-16（有 BOM）和 GB18030，及每条字幕的多行文本。

示例：

    1
    00:00:05,000 --> 00:00:08,000
    我们今天来看看机器人。

    2
    00:00:12,500 --> 00:00:16,000
    双倍能量，直接起飞！

第一句从第 5 秒开始；第 8 秒到第 12.5 秒会自动留白。

## 限制与安全设计

- **字幕时间相互重叠会报错**。目前不支持多角色同时说话；请先合并或编辑字幕时间。
- 句子必须可以在相应的字幕时长内朗读完成；必要时手动缩短文本或延长时长。自动加速最高 +100%，尝试次数最多 3 次，避免无限请求或消耗服务额度。
- 软件的其他句间/行末停顿设置对 SRT 不生效（字幕时间戳优先）。
- 不会剪切已生成的语音。生成失败、主动停止时不会替换已有的目标 MP3；合成成功后才原子替换。
- MP3 编码器本身会引入几十毫秒级的帧取整/起始延迟，极严苛的逐帧口型同步需要在剪辑软件中复核。
- 没有网络时无法实际合成语音；离线测试使用模拟的 TTS 输出，不验证微软服务的可用性。
- 导入功能保留现有的 TTS 依赖（miniaudio 和 lameenc），不需要 FFmpeg。
