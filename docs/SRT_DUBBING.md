# SRT 时间轴配音（Fork 测试功能）

此功能直接集成在**普通模式 → 批量上传**，现在可混合导入 `.txt`、`.md`、`.docx`、`.pdf` 和 `.srt`，不再单独弹出输出文件选择窗口。

## 正常使用

1. 打开普通模式，点击 **批量上传**，导入一个或多个 SRT（也可以与文本文档混合导入）。
2. 导入后 SRT 是普通批量列表的一行：选择音色、语速、音量、音调；点击 **批量生成**。每个 SRT 输出一条完整的 MP3，音频严格按时间轴位置排列，空白时段插入静音。
3. **试听** 直接播放临时缓存的 MP3；**查看结果** 可预览时间轴、播放、拖动进度条。SRT 文字和时间戳须通过批量列表中的 **编辑文本** 或结果预览的 **编辑 SRT** 修改，以免丢失时间信息。
4. 只有用户点击 **保存下载**（导出 ZIP）或在批量列表右键保存单文件时才会询问保存位置，ZIP 内包含对应的 MP3 与原 SRT（如果“生成 SRT 字幕”选项开启），还可选择导出时间轴 JSON。
5. 退出批量模式、从列表删除条目、修改使缓存失效，或者关闭程序时，按项目原有机制清除临时合成音频；不会自动把 MP3 保存到下载文件夹。

默认情况下 SRT 项会勾选“生成 SRT 字幕”，此处表示在 ZIP 中保留原 SRT。SRT 时间轴本身不会被重新生成或覆盖。其他文本文件继续使用原有生成字幕的流程。

支持 UTF-8、UTF-16（含 BOM）和 GB18030 的 SRT 文件；带时间戳的多行字幕会合并朗读。

```srt
1
00:00:05,000 --> 00:00:08,000
我们今天来看看机器人。

2
00:00:12,500 --> 00:00:16,000
双倍能量，直接起飞！
```

第一句从第 5 秒开始，第二句从第 12.5 秒开始，之间自动留静音。

## 时长与错误处理

- SRT 字幕相互重叠、时间戳错误、空字幕都会在导入或编辑阶段被检查。
- 单句语音超过字幕长度时会尝试加快语速，最高 +100%，最多 3 次；仍不足时报告错误，**不会截断内容或造成下一句重叠**。
- SRT 时间戳优先，原软件的额外句间/行末停顿不应用于 SRT。其他 TXT/PDF 的生成行为保持不变。
- 未成功合成的任务不会替换原有结果；批量任务支持取消、失败重试和继续生成未完成文件。
- 语音试听使用项目原有的播放接口；MP3 编码有帧延迟，特别精确的逐帧对齐需在剪辑软件人工核验。
- 微软在线服务需要网络。离线自动化测试无法保证真实服务可用性或所有 Windows 图形环境表现。
- 依赖与原项目一致，不需要安装 FFmpeg。
